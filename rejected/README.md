# ❌ rejected/

This folder represents the **Rejected** stage of the gallery approval workflow.

## Purpose
Files moved here have been **reviewed and rejected by the admin** and will **not** appear in the public gallery.

- Rejected via the [Admin Panel](../admin.html)
- Not visible in the public gallery
- Admin can move rejected items back to Pending for re-review if needed

## Workflow

```
pending/  →  Admin rejects  →  rejected/  →  Not shown in public gallery
```

> **Note:** On this static GitHub Pages site, media is stored securely in the browser's IndexedDB database. The `pending/`, `approved/`, and `rejected/` folders serve as organizational documentation for the approval workflow.
