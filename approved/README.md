# ✅ approved/

This folder represents the **Approved** stage of the gallery approval workflow.

## Purpose
Files moved here have been **reviewed and approved by the admin** and are shown in the public gallery.

- Approved via the [Admin Panel](../admin.html)
- Publicly visible in the [Gallery](../gallery.html)
- Admin can revert approved items back to Pending if needed

## Workflow

```
pending/  →  Admin approves  →  approved/  →  Shown in public gallery
```

> **Note:** On this static GitHub Pages site, media is stored securely in the browser's IndexedDB database. The `pending/`, `approved/`, and `rejected/` folders serve as organizational documentation for the approval workflow.
